# Zenta — Datos que se entienden

**[Ver sitio en vivo →](#)** *(reemplaza este link cuando publiques con GitHub Pages, ver instrucciones abajo)*

Zenta es un proyecto propio de Business Intelligence aplicado a dos frentes: **dashboards para empresas** y **análisis estadístico de fútbol**. Nace de mi experiencia construyendo indicadores, automatizando reportes y depurando datos en entornos financieros y operativos, llevada a un formato de producto que cualquier persona —no solo un analista— pueda entender en segundos.

Este repositorio contiene el sitio web del proyecto: la carta de presentación de Zenta, con dashboards de muestra que ilustran cómo se ve el análisis en la práctica.

## Qué muestra este proyecto

- **Panel de fútbol**: comparación entre dos equipos (xG, posesión, goles recibidos) y una predicción de resultado basada en un modelo estadístico (distribución de Poisson).
- **Panel de BI empresarial**: un reporte operativo tipo el que construyo para empresas — KPIs, variación mensual y tendencia de ventas — con datos ilustrativos.
- **Diseño propio**, coherente con la identidad de marca de Zenta.

> Los datos mostrados en ambos paneles son de muestra, pensados para ilustrar el formato y el tipo de análisis, no resultados reales.

## Stack

| Área | Herramientas |

| Consultas | SQL |

## Publicar el sitio con GitHub Pages (gratis)

1. Sube este proyecto a un repositorio nuevo en tu cuenta de GitHub.
2. Entra a **Settings → Pages** dentro del repositorio.
3. En "Source", selecciona la rama `main` y la carpeta `/root`.
4. Guarda. En un par de minutos tu sitio queda disponible en:
   `https://tu-usuario.github.io/nombre-del-repo/`
5. Copia ese link y ponlo en tu CV y en tu perfil de LinkedIn.
